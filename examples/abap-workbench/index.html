Mockup with fictional data. It mirrors the ARC-1 tools (SAPSearch, SAPRead, SAPContext, SAPNavigate, SAPTransport) but does not call an SAP system. Tool names follow ARC-1; the arguments are simplified.
What is this page?click to collapse

What it shows

A developer's view of an ABAP system: find an object, read its source and its documentation, see where it is used and check which transport requests contain it.

The tabs

Object search, Source code, Where-used and Transports work on the selected object. Ask Joule replays questions with the tool calls behind each answer. Connection shows how the real server is attached.

Demo or real?

The data is fictional and nothing is stored or changed. With the ARC-1 connector installed and a SAP user with display rights, Joule runs the same tools on your system.

Two views of the same hiring pipeline

Dashboard shows the whole process and where hiring is stuck. Pipeline lists candidates per stage with a profile view. The Match agent returns the number of best matches you ask for, with the CV line as proof.

Joule prepares, a person decides

Joule never rejects a candidate and never moves one on its own. Every proposed change waits in Approvals until the hiring manager releases it. Personal fields are removed before the model reads a CV.

Demo or real?

All numbers are computed from fictional sample data. The Werkbank has the recruiting_* tools and a mock import. A real SmartRecruiters connector does not exist yet.

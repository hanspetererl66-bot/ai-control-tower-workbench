How the n8n run works

  1. Import examples/n8n-workflows/04-it-operations-alert-triage.json in n8n (Workflows, Import from file) and switch it to active.
  2. Enter the n8n address in the connector settings (N8N_URL).
  3. Click “Run in n8n”. The chat calls the tool run_it_ops_triage, which posts the alerts to the workflow's webhook /webhook/it-ops-triage and reports the digest. Without your own alerts the workflow uses its sample alerts.

A Space has no network of its own, which is why the call goes through the chat. The workflow and this page use the same rules; a test keeps them equal.

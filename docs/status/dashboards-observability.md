## AI Governance als Einstieg (gemergt 09.11.2026: PR #257, Admin-Kachel entfernt in #258, Smoke-Prüfung in #260)
- Der Space AI Control Tower (`examples/control-tower`) öffnet auf dem Reiter **AI Governance**: vier Kacheln entlang des Agenten-Lebenszyklus (Build → Register → Run → Prove). Die bisherigen Reiter (Executive Dashboard usw.) bleiben dahinter.
- Subspaces (`parent: ai-control-tower`, Domain Governance): **Agent observability** (vorhandener Space, jetzt Subspace), **Agent registry** (Reiter Agent Repository, Agent Usage) und **Agent compliance** (Risk & Compliance, Model Governance, Policies). Registry und Compliance sind aus der Control-Tower-Seite herausgeschnitten (`npm run sync:governance-subspaces`; Test prüft Gleichheit, nach jeder Änderung am Control Tower neu erzeugen), damit die Zahlen nicht auseinanderlaufen. Installieren (die Spaces liegen unter `workspace/spaces/`, nicht im Repo): `node scripts/install-example-space.mjs control-tower agent-registry agent-compliance agent-observability`.
- **Agent development** ist kein Space: die Kachel öffnet das Agent Studio über die Host-Nachricht `wb:open-view` (`src/space-open.ts`, nur `develop` und `studio` erlaubt). Die anderen Kacheln nutzen `wb:handoff`. Studio-Agenten erscheinen auch in der Registry (`studioAgents` für `agent-registry`).
- Die frühere Admin-Kachel "Agent observability" (PR #248) ist entfernt; die Admin console hat wieder drei Kacheln.
- **Nicht installierte Subspaces (09.11.2026):** Die App meldet dem Einstieg (`ct:spaces`, nur an den AI Control Tower, nur Slugs) die installierten Spaces; Kacheln fehlender Subspaces bekommen eine gestrichelte Umrandung und den Hinweis "Not installed yet — click for the install command". Ein Klick zeigt "The Space “agent-registry” is not installed. If it is a bundled example, install it with: node scripts/install-example-space.mjs agent-registry" (12 s; `missingSpaceNotice` in `src/space-handoff.ts`). Außerdem bleibt jede Meldung der App mindestens 4 s stehen, auch wenn der Timer einer früheren sie räumen will (`src/toast-timer.ts`, `createToastGate`). Test: `test/missing-space.test.mjs`. Geprüft in der Electron-App (nur der AI Control Tower installiert: drei Kacheln markiert, Meldung nennt Space und Befehl, nach drei Klicks hintereinander 10 s sichtbar, keine Fehler; mit allen vier Spaces `smoke:governance` 9 von 9). **Nicht getestet:** Nachinstallieren bei laufender App (ob die Markierung ohne Neustart verschwindet), dunkles Design und Telefonbreite der markierten Kachel.
- Prüfung in der echten Electron-App: `npm run smoke:governance` (siehe `CLAUDE.md`, Befehle). Setzt die vier Spaces voraus, braucht Display, klappt die Domain Governance in der Seitenleiste auf. In einem frischen `git worktree` startet Electron nicht (fehlende Sandbox-Einrichtung `chrome-sandbox`, betrifft auch `smoke:electron`); dort die `node_modules` des Hauptverzeichnisses verwenden.
- **Ehrlich:** Subspaces nutzen eine kleine Schablone (fehlende Element-Ids bekommen ein losgelöstes Platzhalter-Element), weil die Seitenskripte alle Reiter befüllen. Geprüft: jsdom und Tests, Headless-Chrome-Screenshots (Einstiegsseite, Registry, Compliance; hell und dunkel, 1280×800) und `smoke:governance` in der Electron-App (Kacheln, Subspaces, Zurück-Button, Agent Studio, keine Skriptfehler). **Nicht getestet:** Reiter Agent Usage, Model Governance und Policies in der App, Studio-Agenten in der Registry, Telefonbreite, Agent Observability außerhalb des Smoke-Klicks. Der Zurück-Button ist nur an der Registry geklickt, nicht an der Compliance-Seite. Die Zahlen der Subspaces sind Beispieldaten des Control Towers. Die überlagerte Werkzeugleiste auf den Reitern mit mehreren Filtern ist behoben (PR #265, siehe `look-and-spaces.md`).

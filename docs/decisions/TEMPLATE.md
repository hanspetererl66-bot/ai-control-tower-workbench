# NNN Titel in einem Satz

- **Status:** vorgeschlagen | entschieden | abgelöst (durch NNN)
- **Datum:** TT.MM.JJJJ (oder "nicht belegt")
- **Entscheider:** Name oder Rolle

**Frage:** Was war zu entscheiden?

**Entscheidung:** Was gilt jetzt? Bei *vorgeschlagen*: was ist offen und was ist der Vorschlag.

**Grund:** Warum so, und was wurde verworfen?

**Folgen:** Was muss geändert werden, was wird dadurch festgelegt oder ausgeschlossen?

**Quellen:** Dokumente, PRs, Code.

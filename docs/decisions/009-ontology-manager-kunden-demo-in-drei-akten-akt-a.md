# 009 Ontology Manager: Kunden-Demo in drei Akten, Akt A zuerst

- **Status:** entschieden
- **Datum:** 13.11.2026
- **Entscheider:** Hans-Peter

**Frage:** Womit erzielen wir beim Ontology Manager den Wow-Effekt für Kunden?

**Entscheidung:** Drei Akte: A "Was geht kaputt, wenn ich das freigebe?" (Auswirkung vor Freigabe), B Begriffe überall sichtbar, C Vorschläge aus echten Quellen mit Beleg. Zielgruppe Kunden-Demo. Umsetzung in der Reihenfolge A, B, C; Dramaturgie der Demo C, B, A.

**Grund:** Verbindung zum Rest der Werkbank wirkt stärker als ein weiterer Editor; A schließt die Lücke der von Hand gepflegten Nutzerlisten.

**Folgen:** Schritt 1 von Akt A (Logik und Tests) ist in `main`. Schritt 2 und 3 stehen aus; B und C hängen an Space-Skript, Feeder-Seed und Rechtsfragen.

**Quellen:** `docs/ontology-demo-concept.md`; `docs/ontology-akt-a-concept.md`; PR #374.

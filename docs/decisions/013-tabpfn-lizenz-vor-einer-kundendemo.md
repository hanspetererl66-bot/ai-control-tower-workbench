# 013 TabPFN-Lizenz vor einer Kundendemo

- **Status:** vorgeschlagen
- **Datum:** 13.11.2026
- **Entscheider:** Hans-Peter

**Frage:** Dürfen wir die Zahlungsverzug-Prognose mit TabPFN in einer Kundendemo zeigen?

**Entscheidung:** Offen. Die Gewichte von TabPFN 2.5 bis 3.5 sind laut Prior-Labs-Dokumentation nur nicht kommerziell nutzbar. Optionen: gehostete API oder kommerzielle Lizenz; bis dahin nur intern, und die Demo "Collections" zeigt ausdrücklich beschriftete Beispielzahlen.

**Grund:** Rechtliche Klärung steht aus.

**Folgen:** Vor der ersten Kundendemo außerhalb des internen Kreises entscheiden.

**Quellen:** `docs/status/cognee-tabpfn.md`; `docs/collections-demo.md`.
